# Maintainers

The people who review and merge changes to Hatamoto. How the role works is in
[`GOVERNANCE.md`](GOVERNANCE.md). The same handles are in
[`.github/CODEOWNERS`](.github/CODEOWNERS), which GitHub uses to request reviews.

| Handle | Role | Areas |
| --- | --- | --- |
| @zenlabscorp | Steward (Zen Labs Corporation) | Everything: code, releases, security, community |

The steward account is currently the only maintainer handle. When more
maintainers join, they are added here and in `CODEOWNERS` in the same pull
request.
