# Getting help

Hatamoto is an open-source project stewarded by Zen Labs Corporation. Help is
given in public, on GitHub, so that the answer helps the next person too.

## Where to ask

| You want to | Go to |
| --- | --- |
| Ask how to do something, share an idea, or show your site | [GitHub Discussions](https://github.com/Zen-Labs-Corp/hatamoto/discussions) |
| Report a bug | [A bug report](https://github.com/Zen-Labs-Corp/hatamoto/issues/new/choose) |
| Report a problem importing a WordPress site | The "WordPress import problem" form in [new issue](https://github.com/Zen-Labs-Corp/hatamoto/issues/new/choose) |
| Ask how to build a plugin | Discussions, or the "Plugin SDK question" form; the SDK lives in [hatamoto-sdk](https://github.com/Zen-Labs-Corp/hatamoto-sdk) |
| Ask for a feature | A feature request issue, after a look at the [roadmap](docs/ROADMAP.md) |
| Report a security problem | **Not** in public: [`SECURITY.md`](SECURITY.md), or security@hatamoto.dev |
| Report a conduct problem | conduct@hatamoto.dev, see [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) |
| Ask about the name or logo | trademarks@hatamoto.dev, see [`TRADEMARKS.md`](TRADEMARKS.md) |

Problems with a third-party plugin or theme belong in that plugin's own
repository.

## Before you ask

- Read the documentation at [hatamoto.dev/docs](https://hatamoto.dev/docs). The
  install, update, themes, plugins and import guides are there.
- Search the issues and discussions for the same question.
- For a bug, give the version (`hatamoto version`), how you run it, what you did
  and what happened, and redact passwords, tokens and private hostnames from logs.

## What to expect

Maintainers answer when they can. The target is a first reply or a label within
5 business days; a security report is acknowledged within 3 business days. Those
are targets for a project run by a small team, not a service-level agreement.
There is no paid support channel in this repository.
