This section has two halves. The guides help you move an existing website into Hatamoto, from WordPress or from another Hatamoto server, and keep every old address working so visitors and search engines never land on a missing page. You need your old site and its admin, and nothing more technical than that.

The reference pages are for developers who want to change Hatamoto itself: build it from source, run the tests, write a safe database change, follow how a release is built and signed, publish plugins through a registry, and update these docs.
