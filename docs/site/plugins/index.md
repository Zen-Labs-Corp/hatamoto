This section is for web developers who want to add a feature to a Hatamoto site without changing the server itself. A plugin can react when content is published, change what a page shows, keep its own data, answer its own web addresses and add a page to the admin. It runs in a closed space and can do only what the site owner allows.

Start with the guides: they take you from what a plugin is, through a first build, to a signed package installed on a site. The examples use Go. The reference pages list every manifest field, hook, host function and limit when you need the exact rules.
