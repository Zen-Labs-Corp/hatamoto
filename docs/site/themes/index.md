A theme decides how your site looks: the HTML of every page, its CSS, its fonts and its images. This section is for web developers who know HTML, CSS and a template language, and are new to Hatamoto. You can start small: a theme that holds one template and one stylesheet already works, because Hatamoto fills in everything else from its built-in theme.

The guides take you from your first theme to a signed package you install on your real site. The reference pages list every file, template function, field kind and rule, for when you need the exact detail. If you have never built a Hatamoto theme, start with [Build your first theme](your-first-theme.md).
