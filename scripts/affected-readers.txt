# file must run those tests at push. Read by .githooks/lib/affected.sh from the pushed tree.
#   <path glob>   <module dir>   <package>
# Globs are repo-relative; `**` and `*` both match across directories. A package is
# module-relative, as `go list` prints it. A non-Go file under backend/ that is neither
# embedded nor listed here makes the push run the full suite, so a missing row costs
# time, never coverage. Paths that force a full run anyway (migrations, the SDK, examples,
# deploy/sql, .github/workflows, the gate scripts) need no row.
# scripts/test-affected.sh fails when a test reads a path no row, embed or force-full rule covers.
